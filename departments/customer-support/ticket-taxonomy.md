# Ticket Taxonomy

Cada ticket interno deve ter categoria, modulo, prioridade e status operacional.

## Categorias

- duvida
- bug
- cobranca
- cancelamento
- sugestao
- onboarding
- seguranca

## Modulos

- login
- alunos
- treinos
- agenda
- pagamentos
- planos
- dashboard
- relatorios
- admin
- suporte

## Prioridades

### Baixa

- Duvida simples sem bloqueio.
- Sugestao de melhoria.
- Pedido de orientacao com alternativa clara.

### Media

- Cliente bloqueado em fluxo importante, mas com workaround.
- Cobranca com duvida, sem risco imediato.
- Onboarding parado sem impacto amplo.

### Alta

- Cliente sem conseguir usar fluxo central.
- Problema de pagamento, plano ou cancelamento com risco comercial.
- Bug afetando varios clientes ou fluxo essencial.

### Critica

- Incidente de seguranca, permissao, dados ou privacidade.
- Falha ampla de login, pagamento ou acesso.
- Cobranca indevida em massa.
- Risco reputacional ou legal.

## Status operacional

- novo
- em triagem
- aguardando cliente
- aguardando humano
- escalado para CTO
- escalado para CEO
- resolvido
- fechado
