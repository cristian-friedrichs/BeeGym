# Schedule Class

## Para quem e

Para clientes que usam a agenda para organizar aulas, turmas ou atendimentos.

## Quando usar

Use este artigo quando quiser agendar uma aula ou atendimento.

## Passo a passo

1. Acesse a agenda.
2. Escolha a data e o horario.
3. Selecione aluno, turma ou atendimento.
4. Revise as informacoes.
5. Salve o agendamento.

## Se nao funcionar

Abra um ticket interno dizendo qual data/horario tentou usar e o que apareceu na tela, sem dados sensiveis.
