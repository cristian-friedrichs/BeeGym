# Account and Login

## Para quem e

Para clientes com dificuldade de acesso.

## Quando usar

Use este artigo quando nao conseguir entrar na conta ou encontrar erro no login.

## Passo a passo

1. Verifique se o e-mail esta correto.
2. Tente novamente a senha cadastrada.
3. Se houver opcao de recuperacao de senha, use o fluxo indicado na tela.
4. Se aparecer erro, copie apenas o texto da mensagem.
5. Abra um ticket interno se o problema continuar.

## Se nao funcionar

No ticket, informe se o erro acontece antes ou depois de carregar a tela. Nao envie sua senha.
