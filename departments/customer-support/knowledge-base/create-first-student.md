# Create First Student

## Para quem e

Para quem quer cadastrar o primeiro aluno no BeeGym.

## Quando usar

Use este artigo quando estiver configurando sua operacao inicial.

## Passo a passo

1. Entre na area de alunos.
2. Escolha criar novo aluno.
3. Preencha os dados obrigatorios.
4. Salve o cadastro.
5. Confirme se o aluno aparece na lista.

## Se nao funcionar

Abra um ticket interno com a tela em que parou e a mensagem exibida.
