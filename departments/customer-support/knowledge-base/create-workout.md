# Create Workout

## Para quem e

Para personal trainers, academias e studios que precisam montar treinos para alunos.

## Quando usar

Use este artigo ao criar ou organizar um treino.

## Passo a passo

1. Acesse a area de treinos.
2. Escolha criar novo treino.
3. Adicione exercicios, series e observacoes necessarias.
4. Vincule o treino ao aluno correto quando aplicavel.
5. Salve e revise o treino.

## Se nao funcionar

Abra um ticket interno informando se o problema ocorreu ao montar, vincular ou salvar o treino.
