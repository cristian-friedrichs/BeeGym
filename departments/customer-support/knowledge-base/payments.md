# Payments

## Para quem e

Para clientes com duvidas sobre pagamento dentro do BeeGym.

## Quando usar

Use este artigo para entender como pedir ajuda sobre pagamento sem expor dados sensiveis.

## Orientacao

Ao abrir ticket interno, informe se o caso e:

- pagamento recusado
- pagamento duplicado
- duvida sobre plano
- teste
- reembolso

Nao envie dados completos do cartao pelo ticket.

## Se nao funcionar

O suporte pode encaminhar casos de cobranca, contestacao ou reembolso para revisao humana.
