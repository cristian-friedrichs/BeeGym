# Getting Started

## Para quem e

Para clientes que estao comecando a usar o BeeGym.

## Quando usar

Use este artigo para entender o primeiro caminho recomendado dentro do app.

## Passo a passo

1. Acesse sua conta no BeeGym.
2. Crie ou revise seus dados principais.
3. Cadastre o primeiro aluno.
4. Crie o primeiro treino.
5. Use a agenda para organizar atendimentos ou aulas.

## Se nao funcionar

Abra um ticket interno informando a etapa em que parou e a mensagem exibida. Nao envie senha, dados completos de cartao ou informacoes sensiveis.
