# Analise de Ativacao

## Objetivo

Analisar como usuarios do BeeGym chegam ao primeiro valor durante o teste de 7 dias.

## Quando usar

Use para onboarding, configuracao inicial, cadastro de alunos, agenda, treinos, unidade, convite, primeira acao relevante ou conversao inicial.

## Entradas necessárias

- Fluxo de ativacao.
- Segmento de usuario.
- Dados ou feedbacks disponiveis.
- Criterio de primeiro valor.
- Lacunas de tracking.

## Processo passo a passo

1. Defina primeiro valor para o segmento.
2. Mapeie passos ate esse valor.
3. Identifique friccoes e pontos de abandono provaveis.
4. Separe dados reais de hipoteses.
5. Sugira melhoria pequena ou investigacao.
6. Marque riscos de produto, tracking ou comunicacao.

## Critérios de qualidade A+

- Primeiro valor e especifico para gestao fitness.
- Analise considera teste com cartao.
- Nao inventa taxa de ativacao.
- Recomenda acao pequena e mensuravel.
- Limites de dados sao claros.

## O que não pode fazer

- Alterar onboarding sem aprovacao.
- Criar automacao de lifecycle.
- Inventar eventos ou dados como se existissem.
- Prometer conversao garantida.

## Output esperado

Analise com primeiro valor, passos, friccoes, evidencias, hipoteses, recomendacao e riscos.

## Checklist final

- [ ] Primeiro valor foi definido.
- [ ] Passos foram mapeados.
- [ ] Friccoes foram listadas.
- [ ] Dados e hipoteses foram separados.
- [ ] Proximo passo foi recomendado.
