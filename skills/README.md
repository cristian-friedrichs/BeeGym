# Skills

Esta pasta sera a biblioteca de skills do BeeGym Operating System.

Ela nao deve conflitar com `.agent/skills`. A pasta `.agent/skills` representa uma estrutura existente de apoio/ferramental; `skills` representa a biblioteca oficial de capacidades reutilizaveis da governanca BeeGym OS.

## Padrao para cada skill

Cada skill deve documentar:

- objetivo;
- quando usar;
- entradas necessarias;
- processo;
- criterios A+ de qualidade;
- limites;
- checklist de execucao;
- exemplos de saida quando util.

## Regras

Skills devem ser praticas, verificaveis e pequenas o suficiente para serem reutilizadas por agentes e departamentos. Uma skill nao deve autorizar acoes sensiveis por conta propria; aprovacoes continuam seguindo as regras do BeeGym Operating System.
